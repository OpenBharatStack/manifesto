# OpenBharatStack 🇮🇳

> "No single entity — foreign or domestic — should control India's critical digital infrastructure."

## What is this?

OpenBharatStack is an open, community-driven movement to build 
interoperable, auditable, and sovereign digital infrastructure for India.

Not a company. Not a startup. A public digital commons.

Like public roads — open for everyone, owned by none.

## Our Principles

- Open standards first — always
- No single company controls any critical protocol
- Interoperability is non-negotiable
- Public auditability by default
- Data portability always
- Forkability is protected
- Distributed governance — forever

## What we are building

- Dependency map of India's digital stack
- Open alternatives to critical foreign dependencies
- Shared interoperable infra layers
- Contribution culture for Indian engineers

## How to contribute

- Star this repo
- Join discussions
- Pick an open issue
- Build shared layers — not clones
